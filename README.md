# Сайт для абитуриентов ФКТиПМ КубГУ

Одностраничный сайт: калькулятор шансов на бюджет, направления с проходными баллами, экзамены, сроки приёма, изменения 2027 года, советы по подготовке с нейросетями и контакты.

## Как открыть

1. Распакуйте архив.
2. Откройте файл `index.html` двойным щелчком. Сайт откроется в браузере.

Сервер не нужен: всё работает прямо с компьютера или флешки. Шрифты подгружаются из Google Fonts. Без интернета сайт останется рабочим, но откроется со стандартными шрифтами.

## Структура

```
index.html      разметка страницы
css/style.css   оформление: цвета, шрифты, вёрстка, тёмная тема
js/data.js      данные: направления, профили, места, проходные баллы
js/main.js      логика: калькулятор, фильтр направлений, кнопка «Скопировать»
```

Чтобы поменять проходные баллы или места, правьте числа в `js/data.js`. Остальные тексты лежат в `index.html`.

## Как выложить в интернет бесплатно

**GitHub Pages**

1. Создайте репозиторий на github.com и загрузите в него все файлы проекта.
2. Откройте Settings → Pages.
3. В Source выберите Deploy from a branch, ветку `main` и папку `/ (root)`, нажмите Save.
4. Через пару минут сайт появится по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

**Netlify Drop**

Откройте app.netlify.com/drop и перетащите туда папку проекта. Сайт сразу получит адрес.

## Технологии

HTML, CSS и JavaScript без библиотек и сборки. Адаптивная вёрстка для телефона и компьютера, светлая и тёмная тема по настройкам системы.
